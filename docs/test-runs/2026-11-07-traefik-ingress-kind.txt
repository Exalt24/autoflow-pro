# 2026-11-07 Traefik in front of the Helm chart on a local kind cluster (kind 0.33.0, node image v1.37.0, Helm 4.3.1, kubectl client 1.36.1, Docker Desktop 29.9.2)
# Traefik: helm install traefik traefik/traefik (chart 42.3.1, Traefik v3.7.17) with service.spec.type=ClusterIP, from `helm repo add traefik https://traefik.github.io/charts`.
# AutoFlow Pro: the chart in deploy/helm/autoflow-pro with deploy/kind/values-kind.yaml plus --set ingress.enabled=true --set ingress.host=autoflow.test.
# The backend image is `docker build -t autoflow-pro-backend:kind-test backend`, loaded with kind load docker-image. The Supabase values are placeholders, so /health is degraded.
# The Ingress annotation traefik.ingress.kubernetes.io/router.entrypoints: web is the one on Traefik's Kubernetes Ingress reference page.
# Not exercised: TLS (no certificate), a cloud load balancer in front of Traefik, the Traefik dashboard. The requests below start inside the cluster (the API pod), so no port on the host is opened.
